# NIT Logo Identification System
An OpenCV-based system developed to detect and identify NIT logos from images and real-time camera feeds using SIFT-based feature matching and image hashing techniques.


## Features

- Real-time NIT logo detection using webcam feed
- Logo detection from uploaded images
- Accurate logo matching using SIFT and image hashing
- User-friendly Tkinter GUI
- Custom NIT logo database for identification
- Fast and reliable logo recognition


## Tools & Technologies Used

- Python
- OpenCV
- NumPy
- Pillow (PIL)
- ImageHash
- Tkinter
- SIFT Feature Matching
